Page Content Scraper

Fetch a page, extract paragraphs, links, and images.

Runs entirely in your browser, plus one server you control. With the render server on, requests go to the server you deployed (see its README for setup) — it loads the page in real headless Chrome, waits for JavaScript to finish, and hands back the final HTML, sidestepping both CORS and JS-only content. With it off, this app fetches the URL directly from your phone's browser, which only works on sites that explicitly allow cross-origin requests. Images are loaded from their original source URLs, so slow or hotlink-protected sites may show broken thumbnails even when the link itself is valid.
