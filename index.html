P-Tag Scraper

Fetch a page, keep only the <p> contents.

Runs entirely in your browser. Direct fetches fail on most sites due to CORS restrictions, so this app can route the request through a public proxy (allorigins.win). Turn the proxy off if the target site allows cross-origin requests directly, or if you're pointing this at your own proxy — see the code comment in index.html to swap the proxy URL.
